# Packet-Tracer-Projects

## Overview

Welcome to my network engineering lab portfolio.

This repository documents my hands-on networking journey as I build the foundational skills required for a cybersecurity career, starting with Cisco Packet Tracer and CompTIA Network+ concepts before progressing into security-specific work.

The goal of this repository is to move beyond theory by building, documenting, and troubleshooting real-world networking scenarios in Cisco Packet Tracer, then carrying that foundation forward into offensive and defensive security labs later in my roadmap.

Throughout this journey, I will be working through structured networking fundamentals (Cisco Networking Academy content, Professor Messer's Network+ course) while expanding on each concept through my own documentation, network diagrams, configuration files, and lessons learned.
