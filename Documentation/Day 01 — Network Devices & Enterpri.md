# Day 01 — Network Devices & Enterprise Topology

## Overview
Built a basic enterprise network topology connecting two branch offices (New York and Tokyo) through a central router, introducing the core devices used in a real enterprise network.

## Devices Used
- 2x Cisco 2911 Routers (branch routers)
- 1x Cisco 2911 Router (central "Internet" router)
- 2x Cisco ASA 5505 Firewalls
- 2x Cisco 2960-24TT Switches
- 2x PCs, 1x Laptop, 2x Servers

## What I Learned
- How routers, switches, firewalls, and endpoints connect to form a basic enterprise network
- The role of an ASA firewall at the edge of a branch network
- How to represent multiple connected sites in Packet Tracer

Topology built — interfaces not yet configured (IP addressing is the next step).
